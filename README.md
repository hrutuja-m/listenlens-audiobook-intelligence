# ListenLens: Audiobook Strategy Intelligence Platform

ListenLens is an audiobook analytics platform designed to compare streaming-based and ownership-based audiobook business models using listener behavior, subscription, completion, recommendation, and churn data.

## Project Objectives

- Analyze listener engagement and completion behavior
- Compare streaming and ownership subscription models
- Identify time-cap friction and unused-credit behavior
- Evaluate genre and narrator performance
- Detect potential churn-risk signals
- Generate product strategy recommendations

## Technology Stack

- Python
- SQL
- DuckDB
- Pandas
- Streamlit
- Pytest
